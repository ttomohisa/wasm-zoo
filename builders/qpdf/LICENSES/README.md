# QPDF release license inventory

The binary release includes QPDF `LICENSE.txt` and `NOTICE.md`, zlib 1.3.2 `LICENSE`, and the Independent JPEG Group libjpeg 9f `README` containing its redistribution/license terms.

The corresponding-source asset additionally carries the full QPDF/zlib/libjpeg sources, immutable Emscripten port recipe/header snapshots from the pinned Emscripten commit, and the WASM Zoo QPDF builder recipe.
