# QPDF canary license inventory

The experimental build copies `LICENSE.txt` and `NOTICE.md` from the exact official QPDF source archive into the build artifact.

The browser binary also links Emscripten's zlib and libjpeg ports. Their exact distribution notices will be promoted into the release-level third-party inventory before QPDF moves from `experimental` to `available`.

No QPDF package Release or npm distribution is authorized by this experimental canary.
