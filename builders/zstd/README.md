# Zstandard builder — reviewed dual-profile upstream automation

Zstandard's official-source `browser-core` library and original `browser-full` CLI have been published after real Chromium and bidirectional native/CLI interoperability tests. The public `@wasm-zoo/zstd@0.3.0` npm package contains only the upstream CLI and is pinned to the immutable `zstd-v0.3.0` Release. Project `v0.15.0` introduced the seven-package 21-cell Registry browser Lab.

The watcher now prepares **review-only** Zstandard promotions. An official stable `facebook/zstd` Release is accepted only with its canonical `vX.Y.Z` tag and full exact commit SHA. Candidate CI substitutes the pins in a throwaway checkout, builds *both* profiles, tests real Chromium operations and malformed frames, requires native-zstd bidirectional interop for `browser-full`, verifies exact corresponding source, both manifests, provenance and SBOM, and tests both staged Playground profiles. Only all-pass candidates may create an automatic promotion PR. No candidate may merge, tag, release, publish or rewrite reviewed `main`.

Existing releases stay immutable. A newer source receives a new Zoo builder patch and manual GitHub Release after review and merge; the published npm version remains separately source-pinned until a second review and manual npm publication. libvips remains adapter-gated.

Local builds: Linux/macOS: `./builders/zstd/build.sh browser-core` and `./builders/zstd/build.sh browser-full`. PowerShell 7: `.\\builders\\zstd\\build.bat browser-core` and `.\\builders\\zstd\\build.bat browser-full`. Set `ZSTD_WASM_BROWSER` to Chrome/Chromium if needed. CI requires native `zstd` for two-way CLI interoperability. Published archives retain upstream BSD license selection, exact source, checksums, in-toto/SLSA provenance and SBOM. The 64 MiB bounded Worker API has no JS streaming, native host filesystem or pthreads. Dictionaries/external codecs are not certified browser capabilities. See `docs/ZSTD_CLI_LAB.md`, `docs/ZSTD_RELEASE.md` and `docs/AUTOMATED_PROMOTIONS.md`.
