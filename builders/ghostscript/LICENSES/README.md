# Ghostscript licensing

The WASM Zoo repository glue is MIT licensed, but the published Ghostscript WebAssembly binary is built from Ghostscript and is distributed under **GNU AGPL v3 or later**. The binary artifact includes `LICENSE-Ghostscript.txt` copied from the exact pinned release source.

The source release includes the exact official Ghostscript source archive and the Zoo recipe used to produce the browser build. Review Ghostscript's bundled third-party notices in that corresponding source before redistribution in another product.
