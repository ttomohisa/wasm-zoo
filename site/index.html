Why Zoo exists

The difficult part is keeping native software buildable and inspectable.

01

Upstream tracking

Daily release checks show exactly when a Zoo pin falls behind.

02

Candidate builds

A new release can trigger an isolated build and real browser smoke test without silently changing the reviewed pin.

03

Capability diff

Expose what is present, absent, target-inapplicable or intentionally removed instead of hiding it behind a package name.

04

Reproducible releases

Exact refs, build info, checksums, license notices and matching source travel with the artifact.
