Why Zoo exists

The difficult part is not the registry. It is keeping native software buildable.

01

Upstream tracking

Pin a real upstream release and show exactly when the WASM build falls behind.

02

Build matrices

Browser/WASI targets, license variants, threading and optional native dependencies produce different artifacts. Zoo records those differences instead of hiding them.

03

Capability diff

Expose what is present, absent or intentionally removed instead of hiding it behind a package name.

04

Reproducible releases

Exact refs, build info, checksums, license notices and matching source travel with the artifact.
